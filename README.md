## ⚡ v2.0.7.26 更新亮点

1. **证卡自动识别与真实物理尺寸自适应注入**：
   - **痛点根治**：以往拉直矫正后，图片在 CorelDraw 中仅保留原图的显示宽度缩放，操作员必须手动查阅并输入标准证件毫米尺寸（如 85.6×54mm），流程繁琐且易输错；
   - **双轨智能匹配引擎**：在图像拉直完成后，无论是快速一键“倾斜矫正”自动长宽比识别，还是在“透视矫正窗口”点击预设，系统自动在 $\pm 2.5\%$ 窄容差内匹配证卡规格字典，自动将导入 CorelDraw 的对象设置为真实标准的物理毫米尺寸；
   - **全面覆盖常用证卡**：
     - **身份证 / 银行卡 / 社保卡**：标准尺寸 `85.6 mm × 54.0 mm`
