## ⚡ v2.0.7.40 更新亮点

1. **高清放大成品质量优化（不动引擎、无新增依赖）**：
   - **修复倍率/模型不匹配造成的细节损失**：realesrgan 的 `-s` 小于模型原生倍率时，引擎内部会用**双线性**降采样；现改为按模型原生倍率出图，缩放交由插件侧 **Lanczos3** 完成，细节不再白丢；
   - **修复跨画风换模型**：原先「要 2x」时会把写实模型（remacri / ultrasharp）换成 anime 模型，导致画风突变；现在保留用户所选模型，仅 animevideov3 系列在同家族内切换 x2 / x3 / x4 版本。
2. **新增输出抖动（Bayer 8x8 有序抖动）**：
   - 显著减少 8-bit 平滑渐变的**色带**，大色块喷绘场景尤为明显；
   - 可通过 `dither:false` 关闭（条码 / 小字等要求绝对保真的场景建议关闭）。
3. **放大日志增强**：记录放大方案（模型 / exe 倍率 / 插件缩放）、引擎耗时与后处理结果，便于评估与调优。
4. **失败安全**：后处理任何异常只记录日志，绝不影响原有放大与导入流程。

## ⚡ v2.0.7.38 历史亮点

1. **修复矢量化误报「未安装 Vector Magic」（模块名劫持根因）**：
   - **根因**：热更机制会在同一 CorelDRAW 进程内加载多个版本目录的原生 DLL，而 .NET 的 `DllImport` 按模块名解析，会绑定到**最先加载的旧版**（没有矢量化导出），于是抛 `EntryPointNotFoundException` 并被误判为「引擎未安装」；
   - **修法**：原生桥不再用模块名绑定，改为**按全路径加载 + 逐个候选校验导出确实存在**，旧版同名模块再也劫持不到，且新版本生效不再依赖加载顺序；
   - **附带修复**：适配引擎的两条路径限制（不能写临时目录根、不能写含中文的路径），固定用 ASCII 工作子目录再由插件拷贝到目标位置（中文目录与文件名照样可用）；引擎目录读取改宽字符，诊断信息更准确。
